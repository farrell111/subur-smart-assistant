# 🏢 Smart Retail Assistant & Analytics Dashboard

Sebuah sistem manajemen terpadu yang dirancang untuk mengotomatisasi layanan pelanggan (*technical support*) dan memvisualisasikan tren data operasional untuk bisnis ritel elektronik (khususnya CCTV dan Komputer). 

Proyek ini dibangun untuk mendemonstrasikan penerapan algoritma pencarian teks dan analisis data dalam memecahkan masalah efisiensi operasional dunia nyata.

## 🚀 Fitur Utama
*   **🤖 AI Tech Support Chatbot:** Asisten virtual interaktif yang menggunakan sistem *scoring* (simulasi Retrieval-Augmented Generation) untuk mencocokkan keluhan pelanggan dengan basis data *troubleshooting* tersembunyi, memberikan panduan perbaikan langkah demi langkah.
*   **📊 Data Analytics Dashboard:** Visualisasi metrik KPI bisnis (resolusi mandiri, rata-rata waktu respons) dan grafik tren volume masalah per kategori (CCTV, Komputer, Jaringan) menggunakan data historis bulanan.
*   **⚙️ Knowledge Base Management:** Antarmuka simulasi bagi admin atau teknisi utama untuk mengawasi dan mengelola basis data solusi teknis.

## 🛠️ Teknologi yang Digunakan
*   **Bahasa Pemrograman:** Python 3
*   **Frontend & Web Framework:** Streamlit
*   **Data Manipulation & Processing:** Pandas
*   **Pencarian Data:** Custom Text-Scoring Logic
